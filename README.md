# SHIMORINMATH — числовая окружность

Интерактивный тренажёр по основам тригонометрии.

## Возможности

- выбор точек на числовой окружности;
- задания «формула → точки» и «точки → формула»;
- последовательная работа с несколькими сериями точек;
- экранная математическая клавиатура;
- мгновенная проверка ответов;
- счётчики верных и неверных решений;
- свободная навигация между заданиями с сохранением черновиков.

## Запуск

Откройте [тренажёр на GitHub Pages](https://skymarine88.github.io/shimorinmath-trig-circle/).

Локально достаточно открыть `index.html` в браузере.
